# Decisiones de arquitectura y producto (ADR)

Un archivo por decisión: `AAAA-MM-DD-<slug>.md`, máximo una página, con cuatro secciones: **Contexto · Decisión · Consecuencias · Alternativas descartadas**.

Se registra una decisión cuando condiciona trabajo futuro: proveedor de IA, dónde se calcula el puntaje, estructura del design system, qué datos nunca se guardan, etc. No se registran detalles de implementación que el código ya explica.

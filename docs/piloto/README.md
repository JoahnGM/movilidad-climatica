# Kit de pilotaje

Material reutilizable para cualquier taller de prueba de la plataforma. Estándar de medición: `docs/estandares/medicion-y-feedback.md`. Investigación: `docs/investigacion/08-pilotaje-ux.md`.

| Archivo | Para qué |
|---|---|
| `protocolo-taller.md` | Agenda de 105 min, roles, materiales, observación, debrief |
| `guion-moderador.md` | Frases exactas del moderador y preguntas |
| `plantilla-registro.md` | Registro de observaciones (tarea · momento · cita · severidad · observador) |
| `consentimiento-informado.md` | Consentimiento de una página, anónimo |
| `pre-encuesta.md` | 3 ítems antes de usar la herramienta |
| `cuestionario-post-uso.md` | 8 ítems con escala, origen y nota de traducción |
| `one-pager.md` | Resumen de una página para participantes |
| `convocatoria.md` | Canales, correo de invitación, criterios de selección |
| `sintesis-plantilla.md` | Cómo consolidar hallazgos en 48 h |
| `micro-encuesta-spec.md` | Especificación de la micro-encuesta de `/resultado` (para implementar en la ola 2) |

Los campos `[entre corchetes]` se completan antes de imprimir. El ejemplo de resultado que se muestra en el taller está en `src/lib/contenido/ejemplo-resultado.ts`.
